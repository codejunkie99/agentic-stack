# Agentic Stack Desktop Preview 0.19.1 — Licensing clarity

Preview 11 makes the repository and downloadable application explicit about
which work is licensed by Avidlive under Apache 2.0 and which components remain
under their original third-party licenses.

## What changed

- Added a root `NOTICE` and a licensing guide covering source, compiled forms,
  adjacent licenses, dependencies, demo tooling, and external references.
- Standardized the project owner name as Avidlive.
- Added the complete Sparkle 2.9.6 license and bundled external notices beside
  the existing SwiftTerm notice in the macOS application.
- Included the root `NOTICE` in both the native app payload and standalone
  server archive.
- Clarified in the README that Agentic Stack does not relicense third-party
  work under Apache 2.0.

## Verification

- Full Python suite: 393 tests and 4 subtests passed.
- The focused packaging and licensing suite passed 14 tests.
- The production macOS build completed with build number 11.
- The DMG passed integrity verification and the mounted app passed strict deep
  code-signature verification.
- The mounted app contains the full Sparkle license, including its bsdiff,
  sais-lite, Ed25519, and signature-verifier notices.
- The packaged server contains the Avidlive `NOTICE`.

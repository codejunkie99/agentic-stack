# Agentic Stack Desktop Preview 0.19.1 — Unified work navigation and personal memory

Preview 10 makes Agentic Stack easier to navigate at any window size and gives
every connected coding agent a clearer shared memory and model-routing surface.

## What changed

- Work now has one stable navigation row for Graph, Conversation, Overview,
  Tasks, Terminal, and Loops. The same row stays reachable at compact sizes and
  while Graph is full page.
- The duplicated dashboard routes are merged into one Overview. Memory groups
  Browse, Personal, Lessons, References, and Exports in one place.
- Personal memory separates stable preferences, current working context, and
  query-specific evidence. Every item keeps its source path and can be opened
  for inspection.
- The composer model picker now has two direct choices: Auto routing with
  Faster, Balanced, or Stronger priorities; or a searchable fixed-model list.
  Recommendations explain the selected model, effort, confidence, signals, and
  fallback while keeping the selected runner fixed.
- Images, PDFs, audio, video, text, and code attachments retain MIME type,
  byte size, digest, and staged local path in the agent-visible manifest.
- Leaving Graph full-page mode for another Work section resets the graph-only
  state, so the Conversation composer remains visible.

## Verification

- Full Python suite: 392 tests and 4 subtests passed.
- Swift debug and production builds passed. Existing Keychain deprecation
  warnings remain; the package has no Swift test target.
- The DMG passed `hdiutil verify`; the mounted app passed strict deep code-signature
  verification and reports version 0.19.1, build 10.
- Native checks covered Graph, Conversation, Overview, Tasks, Terminal, Loops,
  every Memory subpage, Connections, Skills, and Settings.
- At 760 × 650, all six Work tabs and composer controls remained visible.
- Graph full-page → Conversation restored the composer in the installed build.
- Auto Balanced recommended GPT-5.6-Terra at medium effort. Auto Stronger
  recommended GPT-5.6-Sol at extra-high effort and persisted in the composer.

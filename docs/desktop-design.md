# Desktop design references

The desktop redesign uses a grouped navigation rail, a flexible task area and a
contextual evidence inspector. A graphite/indigo palette, restrained dividers,
compact metadata and clear action hierarchy support prolonged reading. These
references informed patterns; their brands, assets and templates are not copied.

| Inspected reference | Applied desktop pattern |
| --- | --- |
| [Jiro, Modboard organizer](https://jiro.build/templates/productivity-automation/modboard-organizer-landing-page-mymodz) | Category navigation, breadcrumb and selection/detail hierarchy for memory |
| [Navbar, Robin Spielmann](https://www.navbar.gallery/navbar/robin-spielmann) and [Buttery](https://www.navbar.gallery/navbar/buttery) | Grouped icon/text navigation, shortcut hints, search, bottom utilities |
| [Footer, Heron AI](https://www.footer.design/sites/heron-ai) | Thin dividers and compact labels for provenance and run metadata |
| [CTA, Langbase](https://www.cta.gallery/cta/langbase) | One primary action with quieter inspect/reset actions |
| [404s, Native Security](https://www.404s.design/sites/native-security) | Recoverable errors retain navigation and separate technical evidence from recovery copy |
| [Unsection, Octolane performance/security](https://unsection.com/section/octolane-performance-security-feature-section) | Measured performance beside source/audit evidence |
| [Bento Grids reference](https://bentogrids.com/shots/cltfyofaf000an8ztrm3gzf2q) | A dominant work panel supported by smaller contextual areas |
| [60fps, model intensity selector](https://60fps.design/shots/chatgpt-model-intensity-slider-interaction) | Explicit current selection and restrained state transitions |

All eight reference pages were inspected by the research task; seven were viewed
visually. Animation playback on the 60fps page was not observed. No reference-page
screenshots are claimed as delivered artifacts.

## Native behavior

Navigation is approximately 224 points; the optional memory inspector is 320
points. The layout keeps a resizable central workspace rather than using fixed
marketing sections. UI text uses native fonts, roughly 14-point body, 12-point
metadata and 20–24-point headings, with a four-point spacing rhythm. Selected
states use both text/shape and color. The sidebar transition respects Reduce
Motion. Native keyboard controls and search shortcuts remain available.

The primary Memory workspace path uses **My project** and original project
sources. **Sample project** stays visibly labeled. Timings come from actual
retrieval, and the measurement disclosure explains caching, token estimates and
excluded answer generation. Error banners offer recovery without hiding the
underlying message. Performance and provenance appear together so a fast empty
result cannot be mistaken for a correct answer.

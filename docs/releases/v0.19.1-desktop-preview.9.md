# Agentic Stack Desktop Preview 0.19.1 — Shared agent context

Preview 9 turns Agentic Stack into one local context layer for Claude Code,
Codex, OpenCode, and Cursor. It also simplifies the native navigation and makes
attached projects recover cleanly when macOS revokes or delays folder access.

## What changed

- `recall_context` answers a natural question across exact sanitized
  conversations, named subagents, shared graph memory, and optional personal
  project context in one read-only MCP call.
- Search and `@` completion filter by tool, model, role, project, and context.
  Results retain timestamps, source paths, role names, and content digests.
- Completed local and cloud tasks can stage one explicit reusable finding as a
  review candidate. Routine completion messages are ignored and acceptance
  remains a human decision.
- Work now keeps Graph, Conversation, Recent work, Tasks, Terminal, and Loops
  visible in a horizontally reachable row at compact sizes.
- Connections is the single tool setup and migration surface. Project adapters
  are limited to Claude Code, Codex, OpenCode, and Cursor.
- Project folder bookmarks persist across launches. Loop filesystem reads run
  in a five-second isolated probe and show a reconnect action instead of
  freezing the route.
- Canceled background discovery requests no longer appear as error banners
  while navigating.

## Verification

- Full Python suite: 390 tests and 4 subtests passed.
- Swift debug and production builds passed. Existing Keychain deprecation
  warnings remain; the package has no Swift test target.
- All 60 RPC actions referenced by native controls have backend handlers; no
  empty button closures remain.
- Installed build 9 passed strict code-signature verification after launch.
- Native checks covered every Work, Memory, Connections, Skills, Insights, and
  Settings route at compact width. The Loops route loaded three real contracts.
- The 2D/3D graph switch and full-page graph both worked against a 16,126-note
  library.
- Selecting GPT-5.6-Luna updated the composer model, and Default was restored.
- Typing `@Codex` returned 2,073 real conversations, including named
  subagents; selecting one produced a removable context chip.
- The packaged MCP exposed seven read-only tools and returned exact visible
  subagent text while excluding hidden reasoning.

# Agentic Stack Desktop Preview 0.19.1 — Agent model router

Preview 8 makes model choice a compact policy control while keeping routing
inside the agent tool layer. It also adds bounded multimodal attachments and a
read-only personal-memory tool shared through the existing local MCP bridge.

## What changed

- **Auto · Balance**, **Auto · Intelligence**, and **Auto · Cost** route each
  message against the selected runner's live model catalog. Fixed models retain
  their model-specific effort controls.
- Every routed run records its selected model, effort, complexity, and reason.
  Routing never changes the runner, session, account, or file-access policy.
- Claude Code, Codex, OpenCode, and Cursor receive `recommend_model` and
  `read_personal_memory` through the installed read-only Agentic Stack MCP
  service. Project preferences stay separate from dynamic current-work context.
- The composer accepts up to eight images, PDFs, audio, video, text, or code
  files, capped at 12 MB each and 24 MB per message. Attachments are hashed and
  staged for the run; encoded payloads are omitted from task history.
- Codex receives image attachments through its native image input. Both runners
  receive explicit staged paths for supported files.

## Verification

- Full Python suite: 388 tests and 4 subtests passed.
- Swift production and debug builds passed. The package has no Swift test target.
- Installed build 8 passed strict code-signature verification after MCP runtime
  calls with bytecode writes disabled.
- Native checks passed at 1040×768 and 800×612: all three auto policies and the
  fixed-model effort path were visible, the picker stayed within the window,
  and a selected file appeared as a removable 45-byte chip with file-only Send
  enabled.
- The bundled MCP returned six read-only tools. A complex image task routed to
  the live Codex catalog's GPT-5.6-Sol at extra-high effort, and personal memory
  returned separate static and dynamic sections.
- ZIP CRC, DMG integrity, embedded runtime imports, packaged source comparison,
  and the exact Sparkle EdDSA enclosure signature passed.
